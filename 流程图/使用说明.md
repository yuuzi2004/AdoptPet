# 流程图使用说明

## 文件说明

本目录包含系统设计中的所有流程图，使用Mermaid语法编写。

### 流程图文件列表

1. **用户注册流程.mmd** - 用户注册的完整流程
2. **用户登录流程.mmd** - 用户登录的完整流程
3. **宠物发布流程.mmd** - 用户发布宠物信息的流程
4. **领养申请流程.mmd** - 用户提交领养申请的流程
5. **管理员审核流程.mmd** - 管理员审核申请的流程
6. **系统架构流程.mmd** - 系统整体架构和数据流转
7. **数据库ER图.mmd** - 数据库实体关系图

## 如何生成图片

### 方法1：在线工具（推荐）

1. 访问 https://mermaid.live/
2. 打开对应的`.mmd`文件，复制内容
3. 粘贴到在线编辑器中
4. 点击右上角"Actions" → "Export PNG"或"Export SVG"
5. 保存图片到本地

**优点**：无需安装，操作简单，支持多种格式导出

### 方法2：VS Code插件

1. 安装VS Code插件：
   - **Markdown Preview Mermaid Support**（预览Mermaid）
   - **Mermaid Preview**（专门预览Mermaid文件）

2. 打开`.mmd`文件
3. 按`Ctrl+Shift+V`（Windows）或`Cmd+Shift+V`（Mac）预览
4. 右键预览窗口 → "导出为图片"

**优点**：集成在编辑器中，方便编辑和预览

### 方法3：命令行工具（适合批量生成）

1. 安装Node.js（如果未安装）
2. 安装mermaid-cli：
   ```bash
   npm install -g @mermaid-js/mermaid-cli
   ```

3. 生成图片：
   ```bash
   # 生成单个文件
   mmdc -i 用户注册流程.mmd -o 用户注册流程.png
   
   # 批量生成所有文件
   mmdc -i *.mmd -o output/
   ```

**优点**：适合批量处理，可集成到CI/CD流程

### 方法4：GitHub/GitLab（自动渲染）

- 将`.mmd`文件上传到GitHub/GitLab仓库
- 在Markdown文件中引用：
  ````markdown
  ```mermaid
  flowchart TD
      A --> B
  ```
  ````
- GitHub/GitLab会自动渲染为图片

**优点**：无需额外工具，适合文档托管

## 图片格式选择

- **PNG**：适合文档插入，支持透明背景
- **SVG**：矢量图，可无损缩放，适合打印
- **PDF**：适合正式文档

## 注意事项

1. 确保Mermaid语法正确，否则无法渲染
2. 复杂流程图建议分段生成，避免节点过多
3. 导出前预览效果，调整节点位置和样式
4. 建议使用深色文字，确保打印清晰

## 快速开始

**最简单的步骤**：
1. 打开 https://mermaid.live/
2. 复制任意`.mmd`文件内容
3. 粘贴 → 导出 → 完成！
